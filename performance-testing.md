# Performance Testing — заметки

## Классификация по целям и задачам

### Performance testing — тестирование производительности

Исследование показателей скорости реакции приложения на внешние воздействия при различной по характеру и интенсивности нагрузке.

Все перечисленные виды относятся к **нефункциональному тестированию**.

### Подвиды

#### 1. Load testing — нагрузочное тестирование

Исследование способности приложения сохранять заданные показатели качества при нагрузке в допустимых пределах и некотором превышении этих пределов — определение «запаса прочности».

`Load → допустимая нагрузка + небольшой запас`

#### 2. Scalability testing — тестирование масштабируемости

Исследование способности приложения увеличивать показатели производительности в соответствии с увеличением количества доступных приложению ресурсов.

`Scalability → увеличиваем ресурсы → смотрим рост производительности`

#### 3. Volume testing — объёмное тестирование

Исследование производительности приложения при обработке различных, как правило больших, объёмов данных.

`Volume → большой объём данных`

#### 4. Stress testing — стрессовое тестирование

Исследование поведения приложения при нештатных изменениях нагрузки, значительно превышающих расчётный уровень, или в ситуациях недоступности значительной части необходимых приложению ресурсов.

`Stress → значительно превышаем расчётную нагрузку`

#### 5. Concurrency testing — конкурентное тестирование

Исследование поведения приложения в ситуации, когда ему приходится обрабатывать большое количество одновременно поступающих запросов, вызывающих конкуренцию между запросами за ресурсы: БД, память, канал передачи данных, дисковую подсистему и т. д.

`Concurrency → много одновременных запросов → конкуренция за ресурсы`

## Быстрая шпаргалка

| Тип | Главная идея |
|---|---|
| Load | допустимая нагрузка и запас |
| Scalability | увеличение доступных ресурсов |
| Volume | большой объём данных |
| Stress | сильное превышение расчётной нагрузки |
| Concurrency | одновременные запросы и конкуренция за ресурсы |
